# Buddy English

毎日30分、ゲーム感覚で続けるアメリカ英語のリスニング&スピーキング練習アプリ。

- Buddy（キャラクター）が話す英語をアメリカ英語の音声合成で聞く（字幕・日本語訳つき）
- マイクに向かって英語で答える
- 発音・単語選びについて Claude からその場でフィードバック
- レベル1（幼稚園レベルの単語）〜レベル6（ネイティブ会話）まで、XPを貯めて自動でレベルアップ
- ストリーク（連続記録）機能つき

## セットアップ

```bash
cd english-app
npm install
cp .env.example .env
# .env を開いて ANTHROPIC_API_KEY を設定
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

## 必須環境

- **Google Chrome または Microsoft Edge**（音声認識 `SpeechRecognition` を使うため。Safari/Firefoxは非対応）
- マイクへのアクセス許可
- `localhost` での実行（本番公開する場合は HTTPS が必須）

## 費用について

- Web Speech API（音声認識・音声合成）は無料
- Claude API はやりとりのたびに従量課金されますが、1日30分程度の利用なら月あたり数ドル程度が目安です
- サーバー(`ANTHROPIC_API_KEY`)は自分のマシン上でのみ使うため、キーが外部に漏れる心配はありません(公開デプロイする場合を除く)

## 使い方のヒント

- 🔊 ボタンでBuddyのセリフをもう一度再生
- 🎤 ボタンを押して話す→もう一度押すか自動で認識終了
- ⏭ ボタンで今のやりとりをスキップして次へ
- 右上のレベルバッジからレベルマップを開いて、解放済みのレベルへ自由にジャンプ可能
